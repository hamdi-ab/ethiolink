# EthioLink

> Web-based influencer campaign tracking and analytics platform for the Ethiopian market.

## Overview
EthioLink helps Ethiopian businesses measure the actual performance of influencer marketing campaigns across TikTok, Telegram, Instagram, and physical storefronts.

- **Stack:** Next.js, TypeScript, Tailwind CSS, PostgreSQL
- **Key Features:**
  - Unique campaign tracking landing pages (`ethiolink.app/c/[code]`)
  - Customer action tracking (Telegram redirects, phone calls, maps, promo code copies)
  - Merchant sales logging (ETB) and reported revenue attribution
  - Brand & Creator analytics dashboards
  - Multi-tenant role-based access control (Brand, Creator, Admin)
